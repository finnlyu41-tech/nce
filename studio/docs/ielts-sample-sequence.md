# 四课学习样例：去社区学习中心

本样例把原创、虚构的 Willow Learning Hub 主题分成四课，每课一个小任务，几课合计听、读、说、写。先明确选择 Academic 或 General Training；前三课共用局部方法训练，第四课分别提供数据比较或信件请求。没有默认替用户选择考试类别。

| 课 | 教学目标 | 素材及范围 |
| --- | --- | --- |
| 听 | 跟到最终确认的日期，区分到达与开始时间 | 预约活动短段合成语音，两题；不是正式音源 |
| 读 | 用原文区分一致、矛盾与信息不足 | 中心使用通知，两题；不代表阅读题型全集 |
| 说 | 直接回答，给相关原因和具体细节 | 熟悉学习活动的短答；45 秒只是练习建议 |
| 写 | Academic：准确比较数据；GT：礼貌说明目的、情况和请求 | Task 1 的 2–4 句 mini；不是完整 150 词回应，更不是 Task 2 |

每条选定路线有 24 份小材料：四课各含示范、引导、独立新题、限时新题和两份延迟复验题。两类别共用前三课，写作素材分开；合计 30 份不同材料。全部由本站原创，情境及数据虚构，没有复制真题库。素材 ID、实际刺激文本和题目关系由测试检查；教案语言、合成语音质量和实际教学效果尚未由专家或学习者验收。

## 教学循环与证据

1. 解释方法，阅读带注释的示范；这两个步骤不产生作答或掌握证据。
2. 引导时保留方法。封闭题需先订正，才能撤提示进入下一份新材料。
3. 独立题隐藏示范与听力原文。可主动取提示，记录中保留提示标记；同时记录学习者是否确认此前未接触材料。
4. 主动开始训练计时后才显示限时题目。听读建议 75／90 秒，口语建议 45 秒，写作建议 180 秒，均为本地小任务建议。计时不能暂停或重置；超时仍保存作品及超时状态。
5. 保留独立与限时题的原始答案／文本、时间、提示、音频请求和反馈方式。听读有答案及原文依据；口写只有自查和修改，明确等待人工／音频评价。
6. 保存一处具体修正或待核验问题。听读保存订正答案；口写保存修改文本。订正不替代人工评分。
7. 从订正起至少隔 24 小时才打开一份不同材料；每次复验后再次等待至少 24 小时。只观察正确、首次材料、学习者确认未见、无提示的局部听读表现；听力还要求一次有效播放。材料曝光和原始作答按相同材料 ID 跨类别核对，切换考试类别不能让共用听、说、信息判断材料重新变成新题。Academic／GT Task 1 材料 ID 和内容不同，仍分别核对。开放回答始终待人工核验。两份复验材料用尽后停止“新题”声明，不把原题轮换伪装成新题。

24 小时是本样例的复习安排，并非 IELTS 官方要求。复验保留真实 `promptId`、`at` 及条件；过早、原题、提示、重播和未确认新材料均不能得到独立保持状态。模型输出固定 `band: null`、`mastery: 'not-assessed'`；点击下一步、短题正确率、字数或自查都不授予掌握或 Band。

## 音频与反馈边界

听力通过浏览器 `speechSynthesis` 实际播放原创英文。播放请求、开始、结束及失败必须属于当前材料和同一次请求。只有完整回调结束，且学习者确认实际听到声音，才能记录为听过。引擎结束事件本身不能检测扬声器是否有声音；“没有声音”会保留失败记录并取消该次听过状态。主动停止、引擎错误、超时回调均不产生有效播放。再次播放保留全部请求和失败，延迟复验中的重播不能计为一次播放的独立表现。

口语复用现有 `Recorder`，不传入评分参考，因此不启用评分服务。最近两遍录音在同一课的练习、反馈与复验步骤之间保留，切换课程、类别或刷新后清除。录音不序列化进文本状态；宿主如要保存真实音频证据，需另行实现并取得适用授权。文本不能评价发音，也不等同实际口语；整个样例没有考官互动、正式四维评分或人工核验。

写作没有自动判分。最小词数只防止空作品，不说明任务、组织、词汇或语法达标。示范与自查不能替代熟悉标准的评阅者。本样例不提供完整四项模拟；阶段末的新完整试卷、听力音源、题型覆盖和口写评阅仍由主线安排。

## 接线

所有实现独立于主导航、地图模型、评分及存储。仅以下文件参与样例：

- `ielts-blueprint/sample-sequence.ts`：原创素材及教学配置。
- `ielts-blueprint/sample-sequence-model.ts`：纯状态转换、音频条件、时间及复验证据。
- `ielts-blueprint/sample-sequence-ui.tsx`：独立 React 组件；使用宿主已有 React 和 Recorder。
- `scripts/test-ielts-sample-sequence.mjs`：无依赖的 Node 模型及素材边界测试。

组件可直接挂载作临时演示；刷新会清除内部状态：

```tsx
import {IELTSSampleSequence} from './ielts-blueprint/sample-sequence-ui';
<IELTSSampleSequence />
```

宿主也可以控制状态；保存、校验、导入和迁移由宿主决定，本组件不新增 storage key：

```tsx
import {useState} from 'react';
import {emptySampleState} from './ielts-blueprint/sample-sequence-model';
const [sequence, setSequence] = useState(emptySampleState);
<IELTSSampleSequence value={sequence} onChange={setSequence} />
```

## 本轮验证

`node scripts/test-ielts-sample-sequence.mjs`：125 项通过。包含无类别拒绝、先教后练、错误后订正、音频失败／过期回调／实际声音确认、原始记录不被覆盖、限时开始与超时、24 小时间隔、材料首次条件、提示、重播、错误、有限新题耗尽、口写待人工核验及类别隔离。额外验证共用听／说／信息判断材料跨类别仍视为已接触，复验跳过其他类别已见的材料；不同 Task 1 素材保持其正确类别。测试使用合成事件验证规则，不宣称实际设备声音已验收。

独立样例及其现有组件依赖的严格 TypeScript 检查通过。React 渲染检查通过：初始类别入口存在、独立听力有播放控件而无原文、限时开始前不输出题干。浏览器真实 TTS、真实麦克风、移动设备布局及实际学习效果尚未验收；本轮没有上线或修改主入口。
