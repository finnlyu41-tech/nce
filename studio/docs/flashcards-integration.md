## 首轮实现范围

保留外层 `State.version=1` 与全部旧字段，增加独立版本的 `flashcards`。词条（Note）保存词、义项、例句与来源；卡片（Card）保存方向和独立排程。标准化词形及释义相同的内容共享词条与排程，来源/例句合并；释义不同保留独立义项，绝不凭小写词覆盖。去重键碰撞必须拒绝而非覆盖。双向卡可分别加入，熟练度分开。

读取旧记录时仅迁移已加入的词卡和个人生词。旧 `due` 原值保留、`box` 留作 legacy 快照；FSRS 状态与真实日志在首次评分后创建，不推算旧次数。同词存在多份旧内容时保留各义项，旧单一排程只分配给原界面使用的最后一份同词内容。无法找到释义的旧词卡保留并明确提示补全，不消失。未知闪卡版本及无效备份拒绝恢复，不覆盖现有记录。

在原「生词复习」/「复习」入口替换词卡部分：到期学习/重学优先，再到期复习，再新卡；翻面前只展示题面，翻面后四档反馈与下次时间。Again 是未想起/答错，Hard 是答对但费力，Good 是正常想起，Easy 是轻松想起。记录实际评分、允许撤销最后一次评分，并保存半途翻面状态。用卡片修订号和翻面状态防止连续点击重复评分。

教材加词保留所有已知册课来源。雅思先提供少量本站原创主题词义、搭配与例句，明确是辅助词卡，非官方题库或分数保证。不下载共享卡组、不导入完整教材/音频，不新增媒体服务。本轮先完成既有词条与原创内容的复习闭环，不支持外部卡包导入。后续本地 UTF-8 TSV/CSV 可采用字段映射、预览确认、GUID 去重和大小/条数限制；不以没有用户卡包为阻塞，也不承诺完整 APKG/模板兼容。

## 算法与依赖

使用固定的 `ts-fsrs@5.4.2`（MIT，npm 发布于 2026-09-01），新增一个无运行时依赖的调度包；不引入优化器或 Anki 应用代码。目标记忆率 0.9，FSRS 默认权重，短学习步 1m/10m、重学 10m；关闭 fuzz 使预览与评分可重复验证。保留供应链策略与锁文件，不以现有 `box` 伪造训练历史。不声称与 Anki 的完整卡组、模板、排序及日界设置完全等价。

日期以绝对毫秒时间存储，是否到期按实际时间判断；当地日期/时区仅用于真实日志和展示，改变时区不能改变到期时刻。首版没有日配额、自动权重优化或跨设备云同步。

来源：[Anki 四档说明](https://docs.ankiweb.net/studying.html)、[Anki FSRS](https://docs.ankiweb.net/deck-options.html#fsrs)、[ts-fsrs API](https://github.com/open-spaced-repetition/ts-fsrs/blob/main/packages/fsrs/README.md)、[ts-fsrs 许可](https://github.com/open-spaced-repetition/ts-fsrs/blob/main/LICENSE)。程序 MIT 不等于教材/音频许可；项目根 README 未声明拥有教材版权，本轮仅连接现有内容到本机学习流程。未导入 NGSL/NAWL/OEWN；未来若选用，须先核验当前内容许可与署名、分享要求。

3. 同词同义跨课及雅思来源归并，不同义不覆盖；双向卡独立。
4. 连续点击不能重复评分，撤销恢复前一次排程；刷新与离线保留翻面/排程；时区及跨日不移动 due。
5. 存储失败明确显示未保存；恢复未知或无效备份不覆盖，词条 HTML 只作文字。旧版备份未含闪卡 namespace 时保留当前 FSRS、评分并仅补入缺失内容，恢复预览明确说明。
6. 类型检查、针对性的模型/备份/词库回归及在线、离线构建通过；实际本地浏览器核对桌面和窄屏主流程，不写生产测试进度。
