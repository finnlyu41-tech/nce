# NCE2 004–006 独立盲解复核

## 读取与交付边界

唯一输入是 `blind-prompts-004-006.json` 中的 courseId、id、scope、context、prompt、options。没有读取 module、accepted、key、matcher、test、作者文档或其他资料。依据题面独立生成 `blind-answers-004-006.json`，共 54 条，按输入次序排列，每条只有 id、answer、variants、issues。每课 18 题；选择题 5 题，其答案原样取一个完整选项，variants 均为空。其余 49 题为受控表达。

本报告未比较答案库或判题器，不能据此确认系统实际接受哪些自然变体。issues 区分语法错误、证据相反、未证实信息、以及仅偏离题目指定词汇的自然表达。

## 自然变体与题面边界

- 004 的 live、study、stay 在仍持续情境下，`have/has + 过去分词` 与 `have/has been + -ing` 都自然。已完成的 upload、bake、test 不因这种变体而自动接纳进行式。
- `review-a-nce2-004-experience-location`：`Tess has never been abroad before.` 与 `Tess has never gone abroad before.` 均与从未出国相符。题目本身提供 be abroad/go abroad。后者为否定经历，不是在断言她去了尚未返回；若只接受 been，会形成语言能力与受控模板匹配的混淆。
- `repair-nce2-004-experience-location`：but 前逗号可省；`Nora has` 与 `she is` 可各自收缩，也可同时收缩。but 的对比不强，但题目指定该词且整句相容。其他 but/and/so 并列句的常规可省逗号边界同样适用。
- `repair-nce2-005-time-ledger` 只要求以 We 开头，第二分句共享主语的 `and have cleaned ...` 是自然变体。诊断双账期题则明确两个分句都保留 we，不能跨题移植省略规则。
- `cancelled/canceled` 为正常英美拼写变体。句首/句末的 yesterday、up to now 可作有限词序变体，前提是题目没有规定开头；规定以特定主语开头的题没有据此列句首时间变体。
- scope 已明确大小写、空白、撇号形状及陈述句有无一个句号的变化。JSON 没有重复枚举这些低层变化；variants 是有限自然例子，不是穷尽所有等价句。直接问句均保留一个问号。
- 某些现在结果也可由美式简单过去自然报告；提示明确 have/has 的题则应以提示约束判断。受控范围外的自然英语不应被解释为英语错误。

## 歧义、未证实及 false-transfer 核查

1. **可直接作答，无阻断性歧义。** 54 题均有足够证据独立给出答案。细微边界已写入逐题 issues；不知道今天日期不妨碍 since April，但妨碍猜测六个月。题面没有提供真实作答历史，故不能核实 repair 所说“保留上一轮首答和订正”是否已实现，也不能推断学生已发生错误或已完成订正。
2. **科普真实性与语法任务分开。** `Paper can be recycled.` 是题面给定的泛指答案；题面把“所有纸”作为概括，但污染纸、涂层纸等现实材料不能仅由这个题干证明实际可回收。盲解没有把标题任务当作已验证的环境科普事实，也没有额外加限定词改变指定范围。
3. **没有将陌生名字判为自由迁移。** Arun、Ezra、Nora、Ravi 等名字，以及城市和物品替换，不单独构成迁移证据。普通联系人配对题仍是有限词库选择；泛指句和数量句也高度受控。
4. **独立阶段仍是有限受控任务。** 多条题面确实要求同时处理干扰项目、时间边界、人数或指代，但词库与句型已明显限定。可以说这些题覆盖多证据选择，不能仅凭标题 independent/review/repair 或换场景宣称开放自由迁移。5 道选择题尤其只支持选项识别证据，不能作为生成表达能力的直接证据。
5. **时间范围不会自动改成习惯。** 005 当前班 `so far in this class` 限定的是本班截至现在的累计毕业人数；006 类别需求才是通常规律。不可把时间范围或重复场景当作简单现在习惯表达的依据。
