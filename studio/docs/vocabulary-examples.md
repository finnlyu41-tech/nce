# 单词双语例句补丁

## 基线与边界

本批响应“单词模块缺少例句”，独立分支为 `codex/vocabulary-examples-20261001`。已只读核对远端 `codex/ielts-map-20260930` 的 `97c85c5` 和正式站 `2026-10-01-mobile-learning-v11`；首轮 FSRS 已由发布负责人整合。只将本批例句提交接到该基线，保留主线的手机样式及评分后时钟刷新。不修改并发工作树，不自行部署整棵支线。

未改动 FSRS 算法、依赖、namespace、迁移或既有用户排程。阅读例句是显示层操作；已有保存的例句/译文优先保留，不能因刷新页面补内容而重新评分。用户主动“加入复习/补充来源”仍走原有统一入词接口，可补双语内容和来源，不重置复习历史。

## 发现的三类缺口

- **有内容但未显示：** 按课词表已经读取本课的双语句子，行组件只把句子交给查词/入词，未在词表显示；已有 12 条原创 IELTS 种子也只显示词义。
- **缺少内容：** 一部分偶数练习课词汇没有对应听读原句；单词索引没有读取上下文，既有 `WordCard` 未显示已保存的例句中译。
- **义项不能直接推断：** 教材的词形命中不是所有词典释义的用法。银行/河岸、书/预订、手表/观看、灯光/轻便、比赛/火柴、公园/停车不能共用一个未标义项的原创例句。

## 实现

`vocabulary-examples.ts` 提供 32 个常用词的 39 条本站原创例句，每条有明确义项、自然英文、中译和常用搭配。只按标准化词形及对应中文义项召回；单字释义使用完整 token，避免“轻浮/书法/看守”误配，停车动作也不匹配“停车处”。词表简释行只展示该行义项的原创例句，中文检索可聚焦对应义项；完整查词保留分别标明的多义内容。没有用万能模板补齐词库。

`VocabularyExamples` 统一显示双语、搭配及来源。按课词表直接显示既有教材上下文，并标识真实册课；第一册偶数练习课的原句标为对应奇数听读课。索引通过“查看教材中的双语例句”显式读取这个词已知的来源课，复用现有缓存和同源资源，无全库后台请求。没有新增或再分发完整教材文本。

查词窗口、词表、原有词卡和 FSRS 揭晓面都展示中译。已有用户例句优先，原创内容仅在义项匹配时补充显示；相同英文句子去重。教材原句标为上下文并提示核对该句语境，不冒充全义项已审读。查词传入的册课是临时显示元数据；本批没有更改备份中例句结构，也不猜测旧保存例句的精确出处。

FSRS 回想正面隐藏新增例句与搭配，按“翻开答案”后才显示；种子卡内容预览也在回想期间收起。教学词表可直接阅读。评分、撤销、去重和旧备份恢复继续由原有接口负责。
