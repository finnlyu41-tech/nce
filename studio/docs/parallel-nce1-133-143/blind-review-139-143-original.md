# NCE1 139–144：54题独立盲解报告

本审核仅依据 `blind-prompts-139-143.json` 的三组 scope、context、prompt 与给定 options；未读取 module、key、matcher、test、作者文档或其他文件，未运行项目源代码。三组各18题，共54题。独立答案写入 `blind-answers-139-143.json`，每题包括 id、answer、variants、issues。答案不为作者预期或测试要求调整。

## 独立作答结论

54题均可按当前限定给出一个语法上成立的答案。7道选择题均只选择给定完整句子，variants 为空；47道输入题保留题面指定主语、动词、时态、未知类型和施事限制，提供有限合理变体。此结论不表示所有题目都能独立证明其声称的语义能力。

139–140组区分是否未知、内容或原因未知、时间未知，以及外层陈述和直接问句。`what has damaged the cable` 与 `what is in the box` 中 what 本身作从句主语，保留 what 后的谓语顺序正确；不能机械地把所有 what 后的 be/has 当成错误倒装。题面没有需要或允许可选 that 的陈述命题补语，故没有为间接问句硬加 that 变体。

141–142组的重复流程使用一般现在被动，过去日志使用一般过去被动。患者接受药物一题保留接受者主语，是双宾语被动的额外组合要求。只在题目允许时保留或省略施事；码头被风暴损坏一题必须保留 by the storm。扫描仪题单独要求 The scanner 开头，未写时间可前置，故其变体不以 On Monday 开头。

143–144组区分截至现在的完成、截至现在仍未发生、明确未来安排或未来否定。never 表示截至现在没有该经历；not yet 不能随意替换 never，也不能把未来承诺当成当前完成事实。原件的未来否定只约束明天，不等于永久不销毁。

## 需要保留的歧义和语义边界

1. **零人获救不能由普通复数否定严格证明。** `review-a-n143-passive-not-yet` 明确要求“到现在没有任何登山者获救”，却指定以 The climbers 开头。`The climbers have not been rescued yet.` 是符合词汇和结构限制的常规答案，但复数集合否定可以描述整组尚未完成获救，不必排除部分已获救。更显式的 `No climbers have been rescued yet.` 能锁定零人，却违反主语限定，不能偷偷作为本题答案。若要测零与部分的区别，需要允许 no/none of，或提供“部分已获救”与“无人获救”的完整命题选择。类似复数否定在乘客未通知、电池未更换、说明未翻译等题也有集合范围边界；这些题没有救援题如此显式的零人声明，因此风险较弱。
2. **否定问句的语用与答复方向尚未被测。** `Was the parcel not given to the resident yesterday?` 与 `Wasn't the parcel given to the resident yesterday?` 均符合规定形式。后者常暗示说话者原先预期包裹已经交付，题面没有明确给出这种预期。只写问句不能证明学习者会按实际交付与否正确理解或回答 yes/no。
3. **already 的疑问或句首位置会带强调。** `Has the payment already been received?` 可用于核实，但可含“比预计更早”的意味。句首 Already 的答案属于可成立的强调表达，未必是无特殊语境的首选。不把合法位置变体当成所有位置都同样自然。
4. **yet 前置不是通用等价变体。** `Yet, the guest has not been served.` 容易把 yet 解作“但是”。有限答案保留 `has not yet been served` 与 `has not been served yet`，没有机械添加句首 Yet。never 前置则需要倒装：`Never has the sensor been calibrated.`；题面许可时间前置，因此保留这个强调型表达，但它不同于普通主语开头模板。
5. **少量情境词义或信息冗余。** 工人题中文“停工”与英文 `waiting` 并非严格同义，答案遵守给定英文问题。座位 `free` 可指免费或空闲，中文明确免费后可解，英文转述仍保留多义词。Jules、付款、包裹等题背景已给出事实后再核实并不构成语法矛盾，但不应据此声称测试真实的信息缺口或会话预期。

## 陌生情境是否只是换词

主体仍然是同一语法骨架换名词、地点、职业或动作：客服与接待员的 whether 从句，电梯与工具的习惯被动，窗户与照片的完成被动，门与报告的未来被动。这些变化能检查指定词汇下的迁移和保持角色，却不足以证明学习者能在自由情境中自己选结构。

较有价值的变化包括：已确认某动作发生、只缺原因或时间；箱子与标签、原件与复印件、今天与昨天的对照；内容、地点、是否未知的选项区分；直接外层问句与嵌套陈述语序；what 主语；主动接受者改成被动主语；保留风暴施事；never 与 not yet；被动否定问句。它们引入了一些真实的语义或角色判断，但多题题面已经显式说出目标时态、否定形式、未知类型和开头，故“陌生情境”主要仍是受控组合迁移。

`repair` 题的“保留上一轮首答和订正”不提供上一轮内容。本盲解只独立回答当前的新情境，没有虚构首答、订正或学习过程。因此不能用这一轮作答证明学习者经过修复后已掌握技能。

## 当前题型能证明与不能证明什么

- 输入题可证明在明确词汇、主语、时态、句式和语境限制下构造句子；选择题可证明识别给定句子与情境的匹配。两者证据应分别记录。
- 题面明确给出“不改时态”“一般过去被动”“will将来被动”等指令时，正确答案不能同时被解释为自主选择时态的证据。
- if/whether、常见缩写、自然状语位置和许可施事保留属于合理的有限变体；大小写、空白、撇号和末句号变化按 scope 处理，不逐一枚举。罕见名词短语缩写没有穷举。存在自然英语变体未列出，并不表示它们是错误英语。
- 当前题型没有充分验证自主写作、真实口语交流、词汇选择、无提示结构选择、否定问句答复、严格的全称/部分否定区分或真实修复轨迹。自由表达仍需伙伴依语义核对。
- what 主语与间接问句组合、被动问句/否定、never和未来否定按题面属于组合扩展；本审核不能仅从题面核实这些结构是否为原课文直接教学内容，也未查看原文或教学实现。
