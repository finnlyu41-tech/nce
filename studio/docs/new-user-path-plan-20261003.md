# 新用户路径优先：2026-10-03 产品指导

Finn 已明确目前没有真实用户使用，批准对代码和产品做必要改造，不必让历史学习记录兼容牵制开发。本指导取代此前以历史草稿键、旧模型字段、旧版恢复或回放字节一致作为新版本发布门槛的做法。旧测试档案和验收证据仍单独留存，不删除归档。

当前先收好已完成的 72 组课程和 mini 批次，避免以大重构拖延可验收成品。已冻结的检查点和成品包不覆盖；后续增量另建提交和验收回执。

mini 1–36 已另存本地检查点 `a8513f7228f1e5af024f96993d6bc50cdce8a574`。随后按真实新用户截图收敛主路线：完成声音/意思热身后，主按钮直接进入第 1–2 课；字母基础仅按需补充，并提供返回正式课的入口。热身需修补时解释具体问题，仍有回主课入口。已有明确选择的起点沿其真实课位，进入后由当前未完/到期/后续课记录继续，避免重复试学卡或回头重做热身。

绕过基础只保存目标课访问许可和当前路线位置，不补造完成、成绩或 FSRS 评分。必要访问保存与当前输入 flush 成功后才跳转，失败时留在当前页并给重试反馈。首十分钟 UI 小批 `790a103274bdd61518401cffde9c490f30c30da5` 串行整合为独立呈现改动；模型、内容、评分和保存事务复用原实现。新路线与该 UI 组合后重新做真实空档案流程和 320/390 验收。

## 本轮最短实施顺序

1. 保留已验收的 72 组＋mini 1–24 检查点；整合下一批 mini 25–36 的最小内容与有限音频接口。
2. 验证当前版全新进入→一个主要继续入口→本课练习→反馈与订正→复习入口。只把当前版新记录的保存、刷新/中断续学、必要失败反馈、320/390 手机视口和最终线上/离线资源作为本轮质量门槛。
3. 在这批成品之后，按同一条学习路径简化老入口、重复提示和相互叠加的路由 guard；复用已有课程、语法、FSRS 与素材，避免为迁就旧架构增加多条主线。

## 测试选择与变更记录

历史版本兼容测试不再阻塞新候选；保留在独立证据中。当前有效需求包括：当前版数据能可靠保存与续学；失败时不误称成功或丢失正在编辑的内容；新任务不会把口写、听过或闭题正确虚称能力达标；一个任务不误写另一个模块的当前成绩；未满足前提时有清楚反馈；主要继续入口唯一且可操作。

不用为了全历史绿灯迁就旧行为。删除或停用旧测试前，记录其代表的旧需求、为何已无效、替代的新用户验收；不能仅为通过测试删断言。本轮不删除历史测试，历史归档不会随本指导迁移或清理。

自然间隔、真人听感、开放口写外评和难度校准仍按事实记录，合成 fixture 与桌面 CSS 视口不能冒充自然达标或实体手机验收。
