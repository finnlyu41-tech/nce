# NCE1 115 / 117 / 119 独立盲解审查

读取来源仅为 `blind-prompts-115-119.json`。未读取 module、key、matcher、tests 或其他 docs。输出 `blind-answers-115-119.json` 共54条：每课18条，id完整且唯一。答案依情境、题干与各课scope独立推导，没有对照既有答案或匹配器。JSON中的variants只列有限的语义等价表达；大小写、空白、撇号和允许的末尾句号差异由scope处理，不穷举。

## 核心结论

54题均可独立作答，没有必须补充材料才能作答的题。3题有值得单独记录的范围或表达问题；没有发现时间线矛盾、指定人物无法对应或正确活动无法选出的情况。以下关于可接受表达是盲解建议，尚未验证现有系统是否接受。

### 1. diagnostic-n115-person-thing：工作人员与有人范围不完全相同

情境说想知道是否有工作人员，题干要求问有没有人。`Is there anyone in the reception room?` 满足题干，但若回答yes，对方可能是访客，不能推出有工作人员。建议把情境的“是否有工作人员”改为“是否有人”；不建议把盲解答案扩大成询问staff，因为那会偏离这组person复合词训练。

### 2. review-b-n115-everyone-agreement：部分否定与全体否定

三人中两人在等车，一人在唱歌，正确概括为 `Not everybody is waiting for the bus.`，scope允许`Not everyone`。`Nobody is waiting for the bus.`与事实冲突。`Everybody is not waiting for the bus.`或缩写式在自然语境下可出现部分否定读法，但范围容易歧义：不宜当作无歧义标准答案，也不宜声称该英语形式在所有语境下都只意味着无人等车。本盲解把明确的句首not作为规范答案，并在issues保留这条边界。

### 3. repair-n117-event-background：门被打开应接受被动

中文给“门被打开”，最忠实表达是 `The actors were trying on hats when the door was opened.`。题干只要求the door与open，并未规定主动语态，`the door opened`也自然。JSON包含两种语态及合理从句顺序。过去进行时必须放在持续的试帽子动作；搬箱子早已结束，不应借用这个干扰词。

## 自然表达与有限变体

- 115：anyone/anybody与someone/somebody依scope同义互换；未知存在问句也接受some复合词。这个接受边界源自scope，不推导成any和some在所有问句中都完全等价。空抽屉/空托盘可写nothing或not anything；room A无人可写no one/nobody或not anyone/not anybody。没有双重否定。
- 115：Everyone/Everybody配单数，正在练习、画画、读剧本用is + -ing；愿望用wants。practising/practicing均记录；无需改动指定动作与宾语。
- 117：when句的事件用一般过去时，持续背景用过去进行时。主句和从句的书写顺序并非事件先后，JSON保留合理排列；while句保留两项过去进行过程与正确角色。
- 117：`label the boxes`的进行形式可以是BrE `labelling`或AmE `labeling`。117的scope未明确提英美拼写，但两者是同一指定动词的正常拼写，不应因115才明确写practising/practicing而把117的labeling排除。
- 119：after/before的两种从句位置都保留事实顺序；早完成用had + 过去分词，后续事件用过去式。Nora在同句再次出现时可用she，仍是同一人物；也记录重复Nora的限定表达。
- 119：未完成的桥/模型用had not finished；未印出的票用had not printed；从未用过相机/从未冲洗照片用had never ... before。未完成不能推成从未开始，曾拍照也不能推成曾冲洗照片。

## 近错边界

115的主要有效边界为人/物、目标地点/别处、全体/部分；on the tray与in the drawer的介词必须跟实际空间搭配。`There is nobody on the tray`不能替代物品为空；room A有棋盘和椅子，所以`There is nothing in room A`与记录冲突。review-b的合唱组不能借用另一个小组的五人全在等车。

117不能只挑题干给出的任意词汇；必须选覆盖参考时刻且属于指定人物的活动。过去式事件和过去进行背景若互换，就改变了持续与突发关系。两项活动先后发生不能用while表示题干要求的并行；把自己的后续任务写成助理的当前任务也不符合角色记录。

119要把参考点前已完成与参考点后才完成的动作区分清楚。after/before连接一般过去时在普通英语中也可自然表达先后，但本课明确要求had，因此双一般过去时是没有完成指定练习，不等于一般英文语法错误。already只用于明确要求它的题；repair-n119-prior-state明确不加already，不能把它当通用变体添入。never与not的范围不同，不可互换。

## 迁移质量：不是仅模板换数字，但结构迁移仍偏窄

全部三课都采用六轮、每轮三项能力的稳定架构。轮次之间不只是更换数字：地点、人称、动作与宾语改变；独立练习与复习加入另一队、另一房间、已结束/尚未开始任务、未完成与从未经历等干扰。119独立练习还给乱序记录，115复习B加入部分否定，具有实质的证据选择和范围判断。

但115大部分仍是“问是否存在→Is there”“零/非零→There is”“全体当前动作/愿望→Everyone”直映；117持续提供明确起止时刻并要求固定when/while，119持续明确指定had与after/before。学生可沿着相同句型选择词条完成，尚未充分检验在未经指定连接词或时态的真实交流里能否自选结构。

- 115：部分否定只在review-b出现，前面五轮的全体题几乎都是肯定，迁移负担在最后突然上升。若要增加同能力迁移，可在不换教学目标的前提下，让前面一轮也出现“并非所有人”或需要排除别组人员的事实。
- 117：不只是数字变动，角色干扰确实增加；但持续时段格式高度重复。可在后续另设题用照片、未完成工序或口头事件顺序提供证据，避免每题都依靠数字区间覆盖。现有题不需要因此判无效。
- 119：从时间表、乱序记录到首次经历的语义转换比单纯换时刻更强；但每题已经点名目标形式。若衡量自由迁移，应另设无形式提示的复述/解释任务；不宜将本组限定输出练习成绩直接等同自由产出能力。

## 建议优先级与统计

先修正115诊断题的工作人员/有人范围，再核实117修复题允许被动与主动表达，最后核实否定范围、从句顺序、正常英美拼写及同指代词是否被公平处理。这些是需交由整合者对照系统的检查点，本盲审没有读取或验证匹配器。

统计：54条答案；每课18条；3条issues非空；无缺题；无重复id。所有题都已有主要答案，剩余工作是整合者检查上述表达与系统实际接受范围的差异。
