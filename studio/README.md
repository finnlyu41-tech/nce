## 完全本地版的既有说明



下载网页直接用浏览器打开；不依赖外部点读网站，不需要登录、云端接口或 CDN。可选本地启动器只绑定 127.0.0.1，使用已安装的 Python 3 标准库，无第三方包。需要保留本地音频或使用麦克风但 file:// 受限时，可从 local-launcher 启动。

## 本地能力

- 全部界面、36 个原创基础单元、24 项原创语法补强、雅思衔接题目和说明随 HTML 打包，共 328 个独立题目。
- 四册 144 / 96 / 60 / 48 课，共 348 个记录区。没有预装四册教材全文、完整词表或原版音频。
- TXT / LRC、常见音频可从本地文件夹批量导入；预览并核对册数与课号，模糊课号必须人工指定；不把 book.json 的目录索引直接当纸质课号。
- 用 NCE1～NCE4 文件夹区分册数；同一路径的同名文本与音频配对，不混淆不同册的同名文件。TXT 和 LRC 同名时优先 LRC。单个文本文件 200 KB / 50,000 字符以内；单份音频 200 MB 以内；每次最多 2,000 个文件、348 组资料。
- 导入时可保留已有资料并补缺，也可明确选择替换所选文本和音频。保留学习进度与笔记。
- 学习状态、文本与音频存入 IndexedDB；旧版 localStorage 记录自动迁移，旧数据不删除。浏览器拒绝 IndexedDB 时只回退保存小容量文字，并显示提示。
- 本地音频持久保存、变速播放；匹配版本的 LRC 支持点击时间戳定位到句子，并在下一时间戳停止。重复时间戳会展开；元信息过滤；暂不应用 LRC offset 偏移。
- 无已导入音频时，只调用 localService=true 的离线英文系统语音。没有本地英文音色时提示使用本地音频或安装系统语音包，绝不回退到联网语音。
- JSON 备份保存文字、进度、生词与笔记。完整 .espack 资料包保存以上内容及已导入音频，不使用 Base64 膨胀音频。
- .espack 先验证版本、边界、课号、音频类型、大小和重复条目；恢复使用单个 IndexedDB 事务，失败时保留原数据。恢复前可导出当前副本。资料包上限 2 GB。
- 跟读录音仅在当前页面保存，不上传、不纳入完整资料包。数据不会自动跨浏览器/设备同步。
- 清理浏览器、移动网页或更换访问地址可能导致原存储不可见，请导出 .espack。直接打开文件与本地启动器是不同存储空间，需用备份迁移。

## 离线边界

最终 HTML 包含 CSP：connect-src none；脚本与样式内联，媒体只允许 blob/data，禁止远程脚本、媒体、图片、字体和接口加载。页面中的来源记录为纯文字，网站不会自动联网获取教材。此约束只作用于学习网页，不控制浏览器扩展或操作系统自身联网行为。

IELTS 官方说明以 2026-09-26 核对的离线摘要提供，不会自动更新。学习工具不提供官方雅思评分，不保证分数。
