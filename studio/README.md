## 构建与教材打包

Node 22.13+、pnpm 11.25.0、Python 3.9+。保留锁文件和现有供应链校验规则。macOS 使用正常 pnpm/Corepack 安装，不使用面向旧云端 Linux 环境的 `install:ci` 包装器；不关闭供应链校验来解决网络或缓存缺失。

从 `studio/` 运行：

```bash
corepack pnpm install --frozen-lockfile
corepack pnpm check
python3 scripts/package-materials.py "$MATERIALS_SOURCE"
python3 scripts/package-speaking.py --source "$SPEAKING_SOURCE" --translations "$SPEAKING_TRANSLATIONS"
python3 scripts/package-lesson-pages.py --source "$MATERIALS_SOURCE"
python3 scripts/package-language.py "$TRANSLATION_SNAPSHOT" "$ECDICT_CSV" "$TRANSLATION_CORRECTIONS"
corepack pnpm verify:materials
corepack pnpm verify:guided
corepack pnpm package:online
corepack pnpm verify:online
```

`MATERIALS_SOURCE` 运行时传入原资料目录，不在源码中保存个人绝对路径。可用 `pnpm` 替代 `corepack pnpm`。若 `pdfinfo` 和 `pdftotext` 在 PATH，打包器会检查所有 PDF 的页数和正文；缺失时记录为未检查，不猜测扫描/正文状态。

打包器只写 `dist-online/materials/`：

- 原文件保持不变；ZIP 逐项读取并校验 CRC，不解压到源代码目录。拒绝路径穿越、符号链接、加密条目、重复路径、膨胀过大的 ZIP 和超限文件。
- 逐册核对 PDF / 音频 / 文本。无法识别册数、标题冲突、字幕课号冲突会停止；排除项和未配对项有明确报告。
- `manifest.json` 每条保留 `id/name/book/lesson/type/size/sha256/parts`，增加配对、口音、扫描状态、页数和课次说明；未知课号为 0。
- 分段为 `/materials/<sha256>/<0000起的序号>.bin`，最多 8 MiB；整份最多 200 MiB / 25 段，最多 2,000 份。现有资料 556 份、561 段，无需提高上限。
- 只在所有源文件处理成功后原子替换清单。构建中的源文件变化会报错；源哈希和排除记录写入 `.inventory.json`。在线构建将该本地证据移至忽略的 `work/local-codex/materials-inventory.json`，不随网站上传。
- `public/materials/manifest.json` 始终为空占位；真实教材与构建结果不进 Git。在线构建保留已有教材分段。

## 阅读、练习与离线

侧栏统一为“新概念 · 四册”。从完整课程目录进入每课，直接在课内使用教材听读、跟练与听写、词句、笔记与本课回顾；“整册资料与下载”作为次级资料入口保留，不再并列显示在侧栏。第一册完整显示 1–144 课，明确区分奇数听读课与偶数句型练习课。

`app/site-materials.tsx` 同时支持课内阅读和整册文件浏览。打开同名配对时校验字幕和音频，支持变速、时间戳点读、下一句停止、隐藏原文练听力和 PDF 阅读/下载。第一册偶数课按核对过的原书目录定位 PDF 页面；第 72 课后的四页测试页已计入偏移，映射仅用于哈希匹配的当前 PDF。四册逐课页码现已核对，并用原 PDF 哈希绑定；换版后必须重新核对。偶数课没有独立录音/字幕时明确说明，不拿相邻奇数课音频替代。浏览器无法内嵌 PDF 时可新窗口打开。

“保存并进入本课练习”通过一个 IndexedDB 事务保存配对文本和音频，接入已有逐句听写、跟读录音、复述、个人词句和阶段语法。已有不同资料默认保留，只有在界面勾选替换后才更换文本/音频，笔记和进度保留。点英文单词打开音标、中文词义与原句，可加入本机生词本。词典包含 7,796 条本次教材、口语题及原创内容用到的词条，来源 ECDICT；音标以英音为主，教材录音为美音。未收录的词明确提示，可在词句区手动填写。

学习状态仍保存在当前浏览器，不自动跨设备同步。完整 `.espack` 备份包含文字、进度和已保存音频；恢复先验证边界、课号、类型、大小和重复条目，再用单个事务恢复。录音仅留在本次页面，不上传或纳入备份。

完全本地版：

```bash
corepack pnpm package:static
```

输出 `dist/index.html`，仅内置原创课程和工作区。保留 TXT / LRC / 音频导入、离线本机语音和现有启动器。离线 HTML 的 CSP 为 `connect-src 'none'`，没有联网语音回退。单课文本 200 KB / 50,000 字符、音频 200 MiB，完整备份上限 2 GiB。在线站与本地文件是不同存储空间，迁移需用备份。

## 课文分层、原书页图与表达引导

276 篇听读课文分开呈现标题、开场指令、听前问题和正文。正文点读、听写与词句提取跳过开场部分，保留原录音和全部原始时间戳；“从正文开始播放”定位正文第一句。自备对话不会仅因首句是疑问句就被误删。听前答案沿用本机草稿保存。

四册 348 课各提供原书前两页，共 696 张图片，可切换或点图放大；第一册偶数课先加载对应练习页，无需先下载整本 PDF。页码记录在 `app/data/nce-pages.json`，绑定当前四份 PDF 哈希。映射依据原书逐页标题识别及异常页人工复核，扫描结果不替代原文。图片仅展示课次前两页，完整课文与后续习题仍可打开完整 PDF；图片内文字不可点击查词。

现有“表达”标签包含五步：理解本课原句、拆句替换、用自己的内容表达、选择一个问题并重练、保存表达卡片。第一册提供按用途组织的句型，第二册练叙事，第三、四册练观点和论证。可逐渐隐藏句架与关键词，示范明确标为本站编写的迁移示范。卡片按用途汇总到已有“学习档案”，并链接到相关口语话题；没有另建课程或学习数据库。

## 口语资料与完整模考记录

按用户提供的历史 Part 1–3 工作簿，整理 66 组话题、238 道中英对照问题：Part 1 为 16 组 / 63 题，Part 2 为 25 张题卡，Part 3 为 25 组 / 150 题。它们是练习素材，不是当前考题预测。个人回答列、私人反馈正文和录音不进入网站或公开 Git。原始工作簿只读，打包时只取题目字段；英文小量拼写修正与本站编写的中文对照在打包输入中保留。

口语区按“想内容 → 连成话 → 脱离提示 → 修一处”引导，提供中文小问题、关键词栏、结构示范、自己的回答、计时与修改记录。录音目前仍用于本页自查回听，不自动诊断或评分。题号进入地址栏，前进、后退和刷新可回到相应题目；每题文字草稿单独保存。

表达、口语、听前答案和模考记录均复用 `State.drafts`，原 JSON / `.espack` 备份直接兼容。完整备份往返检查覆盖新增记录。没有新增账户、自动同步、收费服务或后台任务。

资料构建另需 `pypdfium2`、Pillow 与 `openpyxl`。通过 `SPEAKING_SOURCE` 传入含 Part 1/2/3 工作簿的目录，通过 `SPEAKING_TRANSLATIONS` 传入已核对的中文对照 JSON；先生成题库，再生成扩充词典。脚本只输出到忽略的 `dist-online/speaking/` 和 `dist-online/lesson-pages/`。重新打包完整站点仍需用户提供的教材与语言输入，GitHub 仅保存实现与必要说明。

`pnpm verify:guided` 检查 276 篇分层与时间戳完整性、原句来源、模板、题库字段边界、草稿与完整备份往返、模考条件。`pnpm verify:online` 还检查全部 348 个页码映射、696 张图片及 238 道双语题和发布白名单。

## 学习路径与隔天回顾

现有四册入口和雅思概览共用一条学习路线：一册基础 → 二册运用并在中后段逐步加入雅思 → 三册按弱项选学、雅思专项为主 → 官方材料完整模考。第四册为进阶拓展，不设为雅思 6.5 的必修前置。阶段检查强调理解新材料、独立表达和完整考试反馈，不把册数、勾选或练习正确率换算为分数。

第一册按 72 组呈现完整 144 课，两课均可直接进入，原课号、笔记、音频和步骤记录保留。每组训练使用奇数课的听读、词句与表达，加上该课勾选的配套练习或偶数课的练习记录，按组计一次。四册共 276 组是全库训练统计，不是达到 6.5 的进度条。

每课原有听读、词句、表达和原书练习入口继续使用；初学者先理解、看提示跟读与替换，再减少提示。现有“复述与笔记”中新增理解、听辨和独立表达三项自查，保存在对应 `NceEntry.review`，第一册共享奇数课条目。自查不会自动改动训练勾选。首次或未完全做到时安排下一个本地日回顾；到期复习三项均做到时改为三天后。“今日学习”及四册首页优先显示到期课程，没有到期项时继续当前或下一组。仅在站内显示，不创建后台任务或通知。

旧学习备份无需迁移；JSON 和完整 `.espack` 均保留自查与复习时间，导入时检查项目、重复值和时间边界。验证命令：`pnpm verify:study-path`。带有本地语言包时运行 `pnpm verify:study-path --with-materials`，逐一核验 276 组题目来源与组间差异。

同一册共用的 6 道阶段语法题从课后练习中移走，保留在本册总览与按需语法入口。课内用当前课文生成 3 道原句填空，配合 2–3 句替换表达；明确标作课文回顾，不冒充原书题或雅思评分。第一册奇偶课共用本组课文回顾、偶数课原书练习；其他册逐课取材。答题草稿沿用 `State.drafts` 保存并纳入已有备份，练习反馈只核对原句，不把其他说法判成语法错误。缺少课文时明确提示，不补入通用题冒充本课内容。原书默认折叠，展开后先显示已核对的本课前两页图片；需要更多内容时再读取完整 PDF，并按四册页码映射定位。

36 个原创单元与进度完整保留，移到“备用练习素材”，不再作为并行主线出现在导航；今日学习提供折叠入口。没有添加收费语音生成。原教材听读继续使用原始录音，合成语音只用于原有辅助区。

## 翻译、查词与浏览器导航

`package-language.py` 读取已打包原 LRC、原项目字幕快照、经过核对的少量译文修正和 ECDICT CSV，只写忽略的 `dist-online/language/`。运行时从本站按课读取译文，第一次查词时加载词典，不将学习者课文、查询词或笔记发送到外部翻译服务。

```bash
python3 scripts/package-language.py "$TRANSLATION_SNAPSHOT" "$ECDICT_CSV" "$TRANSLATION_CORRECTIONS"
```

语言包包含 276 个课次 JSON、词典及带哈希的索引；`sourceSha256` 将每课译文绑定到当前原始 LRC。构建需先准备语言包；真实教材及其衍生译文不进公开 Git。词典 MIT 许可保存在 `vendor/ECDICT-LICENSE.txt`，也随词典数据提供。参考来源：[原项目字幕](https://nce.mleo.site/NCE1/book.json)、[ECDICT](https://github.com/skywind3000/ECDICT)。原创雅思听力、阅读、口语题和写作题/范文的中文参考保存在源码中，可随时隐藏。

所有语音区域提供统一的 0.5×、0.7×、0.85×、1×、1.25×、1.5×、2× 调节：教材音频、导入音频、全文与单句听写、单词发音、复习卡、语法例句、雅思听力/口语题、自备课文和录音回放。任一处修改会同步其他控件，当前浏览器记住选择；存储不可用时仍可在本次访问调整。音频播放中即时变速；本机合成语音以新速度重读当前播放片段，不跳到下一句或恢复已停止的朗读。

浏览器地址保存页面、册数、课号、练习标签和雅思任务。前进、后退和刷新恢复相应页面，历史条目保存滚动位置。导航状态不混入学习进度。无新增路由依赖。

四项学习步骤各有“开始学习”和独立的“标记完成”，分别进入教材听读、词句、复述与笔记、本课回顾。第一册课后回顾提供配套偶数课原书的折叠入口。手机端提供单行五项学习标签、可展开的步骤记录、底部上一课/课次选择/下一课、大号点读按钮和固定播放区域。首页底部快捷入口连接今日、新概念、雅思与记录；离线保存收为次级入口。扫描 PDF 可在新窗口阅读。
