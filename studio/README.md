## 构建与教材打包

Node 22.13+、pnpm 11.25.0、Python 3.9+。保留锁文件和现有供应链校验规则。macOS 使用正常 pnpm/Corepack 安装，不使用面向旧云端 Linux 环境的 `install:ci` 包装器；不关闭供应链校验来解决网络或缓存缺失。

从 `studio/` 运行：

```bash
corepack pnpm install --frozen-lockfile
corepack pnpm check
python3 scripts/package-materials.py "$MATERIALS_SOURCE"
python3 scripts/package-speaking.py --source "$SPEAKING_SOURCE" --translations "$SPEAKING_TRANSLATIONS"
python3 scripts/package-lesson-pages.py --source "$MATERIALS_SOURCE"
python3 scripts/package-grammar-pages.py --source "$MATERIALS_SOURCE"
python3 scripts/package-language.py "$TRANSLATION_SNAPSHOT" "$ECDICT_CSV" "$TRANSLATION_CORRECTIONS"
corepack pnpm verify:materials
corepack pnpm verify:grammar
corepack pnpm verify:guided
corepack pnpm verify:pronunciation
corepack pnpm package:online
corepack pnpm verify:online
```

`MATERIALS_SOURCE` 运行时传入原资料目录，不在源码中保存个人绝对路径。可用 `pnpm` 替代 `corepack pnpm`。若 `pdfinfo` 和 `pdftotext` 在 PATH，打包器会检查所有 PDF 的页数和正文；缺失时记录为未检查，不猜测扫描/正文状态。

打包器只写 `dist-online/materials/`：

- 原文件保持不变；ZIP 逐项读取并校验 CRC，不解压到源代码目录。拒绝路径穿越、符号链接、加密条目、重复路径、膨胀过大的 ZIP 和超限文件。
- 逐册核对 PDF / 音频 / 文本。无法识别册数、标题冲突、字幕课号冲突会停止；排除项和未配对项有明确报告。
- `manifest.json` 每条保留 `id/name/book/lesson/type/size/sha256/parts`，增加配对、口音、扫描状态、页数和课次说明；未知课号为 0。
- 分段为 `/materials/<sha256>/<0000起的序号>.bin`，最多 8 MiB；整份最多 200 MiB / 25 段，最多 2,000 份。现有资料 556 份、561 段，无需提高上限。
- 只在所有源文件处理成功后原子替换清单。构建中的源文件变化会报错；源哈希和排除记录写入 `.inventory.json`。在线构建将该本地证据移至忽略的 `work/local-codex/materials-inventory.json`，不随网站上传。
- `public/materials/manifest.json` 始终为空占位；真实教材与构建结果不进 Git。在线构建保留已有教材分段。

## 阅读、练习与离线

侧栏统一为“新概念 · 四册”。从完整课程目录进入每课，直接在课内使用教材听读、跟练与听写、词句、笔记与本课回顾；“整册资料与下载”作为次级资料入口保留，不再并列显示在侧栏。第一册完整显示 1–144 课，明确区分奇数听读课与偶数句型练习课。

`app/site-materials.tsx` 同时支持课内阅读和整册文件浏览。打开同名配对时校验字幕和音频，支持变速、时间戳点读、下一句停止、隐藏原文练听力和 PDF 阅读/下载。第一册偶数课按核对过的原书目录定位 PDF 页面；第 72 课后的四页测试页已计入偏移，映射仅用于哈希匹配的当前 PDF。四册逐课页码现已核对，并用原 PDF 哈希绑定；换版后必须重新核对。偶数课没有独立录音/字幕时明确说明，不拿相邻奇数课音频替代。浏览器无法内嵌 PDF 时可新窗口打开。

“保存并进入本课练习”通过一个 IndexedDB 事务保存配对文本和音频，接入已有逐句听写、跟读录音、复述、个人词句和教材语法索引。已有不同资料默认保留，只有在界面勾选替换后才更换文本/音频，笔记和进度保留。点英文单词打开音标、中文词义与原句，可加入本机生词本。词典包含 7,796 条本次教材、口语题及原创内容用到的词条，来源 ECDICT；音标以英音为主，教材录音为美音。未收录的词明确提示，可在词句区手动填写。

学习状态仍保存在当前浏览器，不自动跨设备同步。旧教材导入及完整资料包工具已删除；专门的进度文件备份见下节。数据库名称、版本和学习记录结构保持不变，不清空已有文字或音频。录音只在本次练习中保留最近两遍，离开或刷新后清除。未点击“提交评估”不会发送录音；启用站内评估后的发送范围见下节。

完全本地版：

```bash

```

输出 `dist/index.html`，内置原创备用课程、教材语法索引和学习工作区，不附教材正文、页图或音频，保留离线本机语音和现有启动器。同一浏览器来源此前保存的课文和音频仍可使用；新安装的本地版没有四册教材，应在在线版学习。离线 HTML 的 CSP 为 `connect-src 'none'`，没有联网语音回退。在线站与本地文件是不同存储空间，记录不会自动同步或迁移。

## 快速保存进度与 iCloud Drive

每页顶部的「保存进度」直接下载带时间戳的 JSON 文件，包含课次进度、笔记、词库、复习安排、练习草稿和自备文字；不包含教材音频、练习录音或评估口令。文件使用 `english-studio-progress` 格式和版本号，最多 25 MiB。保存读取点击时的页面状态，不等待浏览器自动保存完成；页面会区分「正在保存」「本机已保存」和存储失败。

旁边的「进度备份与恢复」可选择系统文件保存位置。支持文件保存选择器的浏览器直接写入所选文件；支持文件分享的设备打开系统面板；其余浏览器回退为下载。学员可选择 iCloud Drive，或将下载文件移入 iCloud Drive，再在另一设备选择「从文件恢复进度」。这是手动文件接续，不是网站后台自动同步；不自动合并进度，也不根据下载或分享面板的返回结果声称 iCloud 上传完成。真正的 CloudKit 同步尚未接入，需另行配置容器、网页登录和冲突处理，参见 [Apple CloudKit JS](https://developer.apple.com/documentation/cloudkitjs)。iCloud Drive 文件接续参见 [Apple 的 iCloud Drive 说明](https://support.apple.com/guide/iphone/set-up-icloud-drive-iphbbcf8827d/ios)。

恢复先检查文件大小、格式版本和已有学习状态约束，兼容以前保存的纯 JSON。显示备份时间与记录数量，用户确认后才替换学习记录；写入浏览器成功后才更新页面，本机教材音频保留。恢复前可保存当前进度；本页还保留一次替换前的内存副本供确认后回退，刷新即清除。`pnpm verify:progress` 覆盖完整字段往返、旧 JSON、损坏或超限文件、原生写入失败、取消、分享与下载回退。

## 课文分层、原书页图与表达引导

276 篇听读课文分开呈现标题、开场指令、听前问题和正文。正文点读、听写与词句提取跳过开场部分，保留原录音和全部原始时间戳；“从正文开始播放”定位正文第一句。自备对话不会仅因首句是疑问句就被误删。听前答案沿用本机草稿保存。

练习按用途收起提示：在线听写默认隐藏中英正文、标题译文、原书图片和跟读参考，用户可主动查看；核对后显示本句答案，换句重新隐藏。本地课文及备用原创课程开启听写时同样收起中英原文。表达的“听懂一句”先听后展开参考，“自己表达”默认关闭句架和关键词；口语“脱离提示”在进入及刷新后收起中文题意和关键词。雅思阅读、写作和口语题的中文参考默认收起。中文操作说明、搭句教学以及明确要求按中文表达的题目保留；已有答案、笔记和复习记录不因隐藏提示被删除。

四册 348 课各提供原书前两页，共 696 张图片，可切换或点图放大；第一册偶数课先加载对应练习页，无需先下载整本 PDF。页码记录在 `app/data/nce-pages.json`，绑定当前四份 PDF 哈希。映射依据原书逐页标题识别及异常页人工复核，扫描结果不替代原文。图片仅展示课次前两页，完整课文与后续习题仍可打开完整 PDF；图片内文字不可点击查词。

现有“表达”标签包含五步：听懂本课一句、拆开搭句、自己表达、反馈与重练、换情境检验。每课从正文选择实际原句，连续字幕片段可合并显示成句，原录音及时间戳不改动；276 组课程当前有 275 个不同的原句片段。根据原句匹配 18 种表达用途，包括物品归属、正在进行、过去经历、条件、原因、转折、比较和事物来历。第二册不再统一使用公园经历、第三四册不再统一使用公园观点。迁移示范为本站编写的有限替换模板，不能视为对每课全部语言点的人工教学设计；第一册先说两句，后续册数增加情境、原因及细节提示。

`app/expression-feedback.ts` 在本机检查写下的内容：少量明确的常见错误（如 I is、can to、didn't went）、照抄原句、过短回答及是否出现本轮表达用途的线索。每次最多显示两个提示，引用实际片段、解释和建议改法；修改版需重新点击检查，再显示已避开的原问题和仍待检查的地方。使用确定性的有限规则，不调用 AI 服务、不上传文字，不声称能识别所有语法问题、判断实际发音或评定雅思分数。用途匹配和展开建议明确标为练习提示，未匹配到也可能是其他正确说法。

最后一步包含按中文意思选择形式的换情境题，以及脱离句架的自己的表达。答题后提供解释，重试换一个示范情境；记录正确选择与有限文字检查结果，并安排下一个本地日回顾，不自动勾选理解、听辨、表达或训练完成。表达卡片保留用途、句型、修改版、换情境表达和再练入口；重练时保留卡片与上一遍迁移表达。旧卡片不伪造检验记录，原文字保留。

新概念表达步骤写入地址栏，前进、后退和刷新可以恢复小步骤；文字和检验沿用 `State.drafts` 在本机保存。“今日学习”直接给出一个约 3–5 分钟的小任务及完成条件。手机表达页折叠课程切换、完成记录和自由笔记，步骤缩为单个选择框，底部操作跟随当前练习；切换步骤后定位并聚焦新标题。没有另建课程、账户或学习数据库。

## 口语资料与完整模考记录

## 逐句录音评估与免费替代入口

在线“跟练与听写”默认提供独立的“跟读纠音”入口：选一句、听原声、录音后手动提交，再练一两处并重录。课文行旁的麦克风也可定位当前句；跟读面板位于正文列表之前，便于手机使用。听写可单独切换，默认不展示参考英文与中文，换句重新隐藏。录音器使用当前句英文作为参考，最多录制 30 秒。此前已保存的课文也可选句跟读；离线模式保留录音和对比，评估不联网。保留最近两遍作比较，语速沿用全站设置。自由复述与雅思口语的录音仍只提供回听，不按原课文逐字评分；文字回答可作前述有限规则检查。表达与重练相邻步骤共用一个录音器，切换时结束录制并保留最近两遍；离开这轮录音练习后清除。

`app/recording-feedback.tsx` 提供录音、用户发送确认、结果与重录对比；`recording-audio.ts` 在浏览器内转换为单声道 16 kHz / 16-bit PCM WAV。反馈最多显示两个需要练习的地方，保留 Azure 返回的 IPA 音素和准确度，优先显示疑似漏读、低匹配单词或音素。对 /θ ð f v s z ʃ ʒ ɪ i ɛ æ/ 提供简短发音要点与例词，其他音素退回原声和单词示范，不猜测读成了哪个音。发音要点参考 [格罗宁根大学美音语音学](https://opentextbooks.rug.nl/americanenglishphonetics2/)，用于练习而非对实际舌位的诊断。可回听问题词附近的录音片段、播放本机美音单词/例词，再重录整句；片段可能包含相邻声音。本机缺少美音时明确提示并保留原声，不切到远程合成。前后两遍按同一词/音素比较，缺少数据或重复词对齐不明时不宣称纠正成功。准确度、连贯度与完整度数据默认折叠，不换算雅思分数。服务未配置时明确显示未启用，并保留 Microsoft Reading Coach 免费替代入口；不会自动向它发送课文或录音。

服务端沿用现有 Pages Worker，只增加 `/api/pronunciation`：GET 返回启用状态；POST 要求同源、个人口令、明确发送确认，并校验文本、请求大小与 WAV 的真实长度/格式，随后调用 Azure 短音频接口。默认不启用额外计费的韵律评估。口令只放在当前页面内存，不写进学习记录；Azure 密钥只由服务端读取。失败保留本页录音，无自动重试、自动购买或升级逻辑，不保存或记录录音正文。

启用前必须由账户持有人在 Azure 核对实际 Speech 资源为 **F0**，确认可用区域和额度；不能把配置字符串当作已核验的资源档位。当前代码及默认部署不含任何 Azure 凭据。仅在明确授权配置后，通过 Cloudflare Pages 的加密 secrets 设置以下四项，不写入源码、构建产物或聊天：

- `AZURE_SPEECH_RESOURCE`：Speech 资源的自定义子域名前缀，例如 `example-speech`，对应 `example-speech.cognitiveservices.azure.com`。
- `AZURE_SPEECH_KEY`：该资源的密钥。
- `STUDIO_SPEECH_TOKEN_SHA256`：至少 16 字符的随机个人口令的 SHA-256；明文口令由使用者保管，在站内输入。
- `STUDIO_SPEECH_ENABLED`：实际核对资源为免费层后设置为 `F0`。缺少任何配置、或设置为付费档位时接口保持关闭。

每项使用 `pnpm exec wrangler pages secret put <变量名> --project-name finn-english-studio` 交互输入。配置后必须重新部署并用本人明确同意提交的一句录音验证返回的真实反馈，才能宣布在线评估可用；模拟结果或配置成功都不代表已经验收。

`pnpm verify:pronunciation` 覆盖 WAV、权限、发送确认、大小与时长、未配置/付费标记关闭、上游错误、仅转写而无评分的拒绝、结果映射及静态路由边界，并在真实 Workerd 运行时检查成功响应与 301/302/307/308 拒绝。请求使用 `redirect: manual`，任何非成功响应都直接拒绝，不会转发密钥或录音到重定向地址。它使用模拟服务响应，不调用真实 Azure。浏览器预览使用 `pnpm exec wrangler pages dev dist-online --ip 127.0.0.1 --port 4188 --compatibility-date 2026-05-22`，兼容当前锁定的本地 Worker 运行时。

## 学习路径与隔天回顾

现有四册入口和雅思概览共用一条学习路线：一册基础 → 二册运用并在中后段逐步加入雅思 → 三册按弱项选学、雅思专项为主 → 官方材料完整模考。第四册为进阶拓展，不设为雅思 6.5 的必修前置。阶段检查强调理解新材料、独立表达和完整考试反馈，不把册数、勾选或练习正确率换算为分数。

第一册按 72 组呈现完整 144 课，两课均可直接进入，原课号、笔记、音频和步骤记录保留。每组训练使用奇数课的听读、词句与表达，加上该课勾选的配套练习或偶数课的练习记录，按组计一次。四册共 276 组是全库训练统计，不是达到 6.5 的进度条。

每课原有听读、词句、表达和原书练习入口继续使用；初学者先理解、看提示跟读与替换，再减少提示。现有“复述与笔记”中新增理解、听辨和独立表达三项自查，保存在对应 `NceEntry.review`，第一册共享奇数课条目。自查不会自动改动训练勾选。首次或未完全做到时安排下一个本地日回顾；到期复习三项均做到时改为三天后。“今日学习”及四册首页优先显示到期课程，没有到期项时继续当前或下一组。仅在站内显示，不创建后台任务或通知。

原先本册总览与按需语法入口中的 6 道阶段补强题，现已由教材索引替代。课内用当前课文生成 3 道原句填空，配合 2–3 句替换表达；明确标作课文回顾，不冒充原书题或雅思评分。第一册奇偶课共用本组课文回顾、偶数课原书练习；其他册逐课取材。答题草稿沿用 `State.drafts` 保存并纳入进度文件，练习反馈只核对原句，不把其他说法判成语法错误。缺少课文时明确提示，不补入通用题冒充本课内容。原书默认折叠，展开后先显示已核对的本课前两页图片；需要更多内容时再读取完整 PDF，并按四册页码映射定位。

36 个原创单元与进度完整保留，移到“备用练习素材”，不再作为并行主线出现在导航；今日学习提供折叠入口。没有添加收费语音生成。原教材听读继续使用原始录音，合成语音只用于原有辅助区。
