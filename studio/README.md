## 构建与教材打包

Node 22.13+、pnpm 11.25.0、Python 3.9+。保留锁文件和现有供应链校验规则。macOS 使用正常 pnpm/Corepack 安装，不使用面向旧云端 Linux 环境的 `install:ci` 包装器；不关闭供应链校验来解决网络或缓存缺失。

从 `studio/` 运行：

```bash
corepack pnpm install --frozen-lockfile
corepack pnpm check
python3 scripts/package-materials.py "$MATERIALS_SOURCE"
python3 scripts/package-language.py "$TRANSLATION_SNAPSHOT" "$ECDICT_CSV" "$TRANSLATION_CORRECTIONS"
corepack pnpm verify:materials
corepack pnpm package:online
corepack pnpm verify:online
```

`MATERIALS_SOURCE` 运行时传入原资料目录，不在源码中保存个人绝对路径。可用 `pnpm` 替代 `corepack pnpm`。若 `pdfinfo` 和 `pdftotext` 在 PATH，打包器会检查所有 PDF 的页数和正文；缺失时记录为未检查，不猜测扫描/正文状态。

打包器只写 `dist-online/materials/`：

- 原文件保持不变；ZIP 逐项读取并校验 CRC，不解压到源代码目录。拒绝路径穿越、符号链接、加密条目、重复路径、膨胀过大的 ZIP 和超限文件。
- 逐册核对 PDF / 音频 / 文本。无法识别册数、标题冲突、字幕课号冲突会停止；排除项和未配对项有明确报告。
- `manifest.json` 每条保留 `id/name/book/lesson/type/size/sha256/parts`，增加配对、口音、扫描状态、页数和课次说明；未知课号为 0。
- 分段为 `/materials/<sha256>/<0000起的序号>.bin`，最多 8 MiB；整份最多 200 MiB / 25 段，最多 2,000 份。现有资料 556 份、561 段，无需提高上限。
- 只在所有源文件处理成功后原子替换清单。构建中的源文件变化会报错；源哈希和排除记录写入 `.inventory.json`。在线构建将该本地证据移至忽略的 `work/local-codex/materials-inventory.json`，不随网站上传。
- `public/materials/manifest.json` 始终为空占位；真实教材与构建结果不进 Git。在线构建保留已有教材分段。

## 阅读、练习与离线

侧栏统一为“新概念 · 四册”。从完整课程目录进入每课，直接在课内使用教材听读、跟练与听写、词句、笔记及语法补强；“整册资料与下载”作为次级资料入口保留，不再并列显示在侧栏。第一册完整显示 1–144 课，明确区分奇数听读课与偶数句型练习课。

`app/site-materials.tsx` 同时支持课内阅读和整册文件浏览。打开同名配对时校验字幕和音频，支持变速、时间戳点读、下一句停止、隐藏原文练听力和 PDF 阅读/下载。第一册偶数课按核对过的原书目录定位 PDF 页面；第 72 课后的四页测试页已计入偏移，映射仅用于哈希匹配的当前 PDF。偶数课没有独立录音/字幕时明确说明，不拿相邻奇数课音频替代。浏览器无法内嵌 PDF 时可新窗口打开。

“保存并进入本课练习”通过一个 IndexedDB 事务保存配对文本和音频，接入已有逐句听写、跟读录音、复述、个人词句和阶段语法。已有不同资料默认保留，只有在界面勾选替换后才更换文本/音频，笔记和进度保留。点英文单词打开音标、中文词义与原句，可加入本机生词本。词典包含 7,684 条本次教材和原创内容用到的词条，来源 ECDICT；音标以英音为主，教材录音为美音。未收录的词明确提示，可在词句区手动填写。

学习状态仍保存在当前浏览器，不自动跨设备同步。完整 `.espack` 备份包含文字、进度和已保存音频；恢复先验证边界、课号、类型、大小和重复条目，再用单个事务恢复。录音仅留在本次页面，不上传或纳入备份。

完全本地版：

```bash
corepack pnpm package:static
```

输出 `dist/index.html`，仅内置原创课程和工作区。保留 TXT / LRC / 音频导入、离线本机语音和现有启动器。离线 HTML 的 CSP 为 `connect-src 'none'`，没有联网语音回退。单课文本 200 KB / 50,000 字符、音频 200 MiB，完整备份上限 2 GiB。在线站与本地文件是不同存储空间，迁移需用备份。

## 公开访问与部署

唯一发布目标是独立 Cloudflare Pages 项目 `finn-english-studio`，生产分支 `main`，地址为 https://finn-english-studio.pages.dev/ 。用户于 2026-09-26 明确将原邀请制决定改为任何人直接访问，不再要求用户名或密码。学习记录仍保存在各自浏览器，没有服务器账号或跨设备同步。

## 翻译、查词与浏览器导航

`package-language.py` 读取已打包原 LRC、原项目字幕快照、经过核对的少量译文修正和 ECDICT CSV，只写忽略的 `dist-online/language/`。运行时从本站按课读取译文，第一次查词时加载词典，不将学习者课文、查询词或笔记发送到外部翻译服务。

```bash
python3 scripts/package-language.py "$TRANSLATION_SNAPSHOT" "$ECDICT_CSV" "$TRANSLATION_CORRECTIONS"
```

语言包包含 276 个课次 JSON、词典及带哈希的索引；`sourceSha256` 将每课译文绑定到当前原始 LRC。构建需先准备语言包；真实教材及其衍生译文不进公开 Git。词典 MIT 许可保存在 `vendor/ECDICT-LICENSE.txt`，也随词典数据提供。参考来源：[原项目字幕](https://nce.mleo.site/NCE1/book.json)、[ECDICT](https://github.com/skywind3000/ECDICT)。原创雅思听力、阅读、口语题和写作题/范文的中文参考保存在源码中，可随时隐藏。

所有语音区域提供统一的 0.5×、0.7×、0.85×、1×、1.25×、1.5×、2× 调节：教材音频、导入音频、全文与单句听写、单词发音、复习卡、语法例句、雅思听力/口语题、自备课文和录音回放。任一处修改会同步其他控件，当前浏览器记住选择；存储不可用时仍可在本次访问调整。音频播放中即时变速；本机合成语音以新速度重读当前播放片段，不跳到下一句或恢复已停止的朗读。

浏览器地址保存页面、册数、课号、练习标签和雅思任务。前进、后退和刷新恢复相应页面，历史条目保存滚动位置。导航状态不混入学习进度。无新增路由依赖。

四项学习步骤各有“开始学习”和独立的“标记完成”，分别进入教材听读、词句、复述与笔记、原书练习。第一册奇数课的练习入口打开紧随其后的偶数练习课原书。手机端提供两行标签、较大的点读按钮、底部切课、逐句中文和点词弹窗；扫描 PDF 可在新窗口阅读。
