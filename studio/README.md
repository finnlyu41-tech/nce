独立的新概念四册学习网站。应用只在 `studio/` 内开发，仓库根目录原网站保持原样。支持在线教材阅读与听读，也保留完全本地版与 IndexedDB 学习记录。旧教材文件导入和 `.espack` 完整资料包工具已移除；学习进度可通过顶部专门的保存与恢复入口备份。原有学习记录、已保存课文与音频继续读取。

## 板块与学习入口

主导航统一为「学习、课程、复习」。学习页只有当前下一步和到期复习入口；课程页集中四册目录、教材词汇、语法检索、雅思与备用素材；复习页先显示到期用法，再显示词卡，词库与补充资料按需展开。学习记录和进度文件保留在顶部及侧栏次级入口，手机底部同样只有三个主入口。

课内统一为「课文、讲解、练习」。四册全部 348 个课次沿现有教材映射组织成 276 组、97 个用法：先听懂大意，再看本课讲解，依次跟着做、合上提示独立表达、用在自己的情境中。讲解主按钮进入当前选中的知识点，不再用课文中的通用关键词猜测本课目标；例如第一册 99–100 课围绕宾语从句。原书页码、层次检索、原声、词表、漫画和可选录音继续复用。

每个用法提供三道不同参考题和一个对应的自由表达任务。核对只判断与参考表达是否一致，不将其他写法判错；自由表达仅提供少量文字规则反馈并保留「待核对」状态。跟练、使用提示、独立核对和不同日期换题核对分别记录，不把自报完成、同日反复作答或未检出错误标为掌握。遇到困难可直接回听课文、查看讲解或回看句架。

旧 `#nce`、课次、词句、表达步骤及雅思任务地址继续可用。`tab=words` 打开讲解下的词句，`tab=notes` 打开练习下的旧表达、自查与笔记。新记录放在 `State.drafts` 的独立命名空间，第一册奇偶课共享课程组记录；旧草稿、词卡、笔记、完成勾选和已保存音频不迁移、不清空，进度文件包含新旧记录。

## 构建与教材打包

Node 22.13+、pnpm 11.25.0、Python 3.9+。保留锁文件和现有供应链校验规则。macOS 使用正常 pnpm/Corepack 安装，不使用面向旧云端 Linux 环境的 `install:ci` 包装器；不关闭供应链校验来解决网络或缓存缺失。

从 `studio/` 运行：

```bash
corepack pnpm install --frozen-lockfile
corepack pnpm check
python3 scripts/package-materials.py "$MATERIALS_SOURCE"
python3 scripts/package-speaking.py --source "$SPEAKING_SOURCE" --translations "$SPEAKING_TRANSLATIONS"
python3 scripts/package-lesson-pages.py --source "$MATERIALS_SOURCE"
python3 scripts/package-grammar-pages.py --source "$MATERIALS_SOURCE"
python3 scripts/package-language.py "$TRANSLATION_SNAPSHOT" "$ECDICT_CSV" "$TRANSLATION_CORRECTIONS"
corepack pnpm verify:materials
corepack pnpm verify:grammar
corepack pnpm verify:guided
corepack pnpm verify:pronunciation
corepack pnpm verify:illustrations
corepack pnpm package:online
corepack pnpm verify:online
```

`MATERIALS_SOURCE` 运行时传入原资料目录，不在源码中保存个人绝对路径。可用 `pnpm` 替代 `corepack pnpm`。若 `pdfinfo` 和 `pdftotext` 在 PATH，打包器会检查所有 PDF 的页数和正文；缺失时记录为未检查，不猜测扫描/正文状态。

打包器只写 `dist-online/materials/`：

- 原文件保持不变；ZIP 逐项读取并校验 CRC，不解压到源代码目录。拒绝路径穿越、符号链接、加密条目、重复路径、膨胀过大的 ZIP 和超限文件。
- 逐册核对 PDF / 音频 / 文本。无法识别册数、标题冲突、字幕课号冲突会停止；排除项和未配对项有明确报告。
- `manifest.json` 每条保留 `id/name/book/lesson/type/size/sha256/parts`，增加配对、口音、扫描状态、页数和课次说明；未知课号为 0。
- 分段为 `/materials/<sha256>/<0000起的序号>.bin`，最多 8 MiB；整份最多 200 MiB / 25 段，最多 2,000 份。现有资料 556 份、561 段，无需提高上限。
- 只在所有源文件处理成功后原子替换清单。构建中的源文件变化会报错；源哈希和排除记录写入 `.inventory.json`。在线构建将该本地证据移至忽略的 `work/local-codex/materials-inventory.json`，不随网站上传。
- `public/materials/manifest.json` 始终为空占位；真实教材与构建结果不进 Git。在线构建保留已有教材分段。

## 快速保存进度与 iCloud Drive

每页顶部的「保存进度」在普通浏览器中下载带时间戳的 JSON 文件，主屏幕 App 中优先打开系统文件保存／分享面板。文件包含课次进度、笔记、词库、复习安排、练习草稿和自备文字；不包含教材音频、练习录音或评估口令。文件使用 `english-studio-progress` 格式和版本号，最多 25 MiB。保存读取点击时的页面状态，不等待浏览器自动保存完成；页面会区分「正在保存」「本机已保存」和存储失败。

旁边的「进度备份与恢复」可选择系统文件保存位置。支持文件保存选择器的浏览器直接写入所选文件；支持文件分享的设备打开系统面板；其余浏览器回退为下载。学员可选择 iCloud Drive，或将下载文件移入 iCloud Drive，再在另一设备选择「从文件恢复进度」。这是手动文件接续，不是网站后台自动同步；不自动合并进度，也不根据下载或分享面板的返回结果声称 iCloud 上传完成。真正的 CloudKit 同步尚未接入，需另行配置容器、网页登录和冲突处理，参见 [Apple CloudKit JS](https://developer.apple.com/documentation/cloudkitjs)。iCloud Drive 文件接续参见 [Apple 的 iCloud Drive 说明](https://support.apple.com/guide/iphone/set-up-icloud-drive-iphbbcf8827d/ios)。

恢复先检查文件大小、格式版本和已有学习状态约束，兼容以前保存的纯 JSON。显示备份时间与记录数量，用户确认后才替换学习记录；写入浏览器成功后才更新页面，本机教材音频保留。恢复前可保存当前进度；本页还保留一次替换前的内存副本供确认后回退，刷新即清除。`pnpm verify:progress` 覆盖完整字段往返、旧 JSON、损坏或超限文件、原生写入失败、取消、分享与下载回退。

## 课文分层、原书页图与表达引导

## 逐句录音评估与免费替代入口

在线「课文跟读」将当前句、随句漫画和录音放在同一处：听一句、录音后手动提交，再练一两处并重录。课文行旁的麦克风也可定位当前句；跟读面板位于正文列表之前，便于手机使用。听写可单独切换，默认不展示参考英文与中文，换句重新隐藏。录音器使用当前句英文作为参考，最多录制 30 秒。此前已保存的课文也可选句跟读；离线模式保留录音和对比，评估不联网。保留最近两遍作比较，语速沿用全站设置。自由复述与雅思口语的录音仍只提供回听，不按原课文逐字评分；文字回答可作前述有限规则检查。表达与重练相邻步骤共用一个录音器，切换时结束录制并保留最近两遍；离开这轮录音练习后清除。

`app/recording-feedback.tsx` 提供录音、用户发送确认、结果与重录对比；`recording-audio.ts` 在浏览器内转换为单声道 16 kHz / 16-bit PCM WAV。反馈最多显示两个需要练习的地方，保留 Azure 返回的 IPA 音素和准确度，优先显示疑似漏读、低匹配单词或音素。对 /θ ð f v s z ʃ ʒ ɪ i ɛ æ/ 提供简短发音要点与例词，其他音素退回原声和单词示范，不猜测读成了哪个音。发音要点参考 [格罗宁根大学美音语音学](https://opentextbooks.rug.nl/americanenglishphonetics2/)，用于练习而非对实际舌位的诊断。可回听问题词附近的录音片段、播放美音单词/例词，再重录整句；片段可能包含相邻声音。在线示范通过同源 `/api/demo-audio` 播放 Azure 美音 MP3，无需手机安装语音包；离线版仍只使用本机美音。示范、本人录音与课文原句互斥播放，示范沿用共享语速；加载、停止、失败均在问题词旁反馈，失败可直接回听原句。前后两遍按同一词/音素比较，缺少数据或重复词对齐不明时不宣称纠正成功。准确度、连贯度与完整度数据默认折叠，不换算雅思分数。服务未配置时明确显示未启用，并保留 Microsoft Reading Coach 免费替代入口；不会自动向它发送课文或录音。

结束录音后先等待最后一段音频写完，再释放该次麦克风；每次采集独立清理，保存期间禁止启动另一遍。回放前实际解码并转换为有明确时长的单声道 WAV，过短、损坏或无可检测声音的片段会提示重录，保留上一遍有效录音。换源时重新创建播放器；取消或离开练习后，迟到的麦克风授权不会启动录音。`pnpm verify:recording` 覆盖连续重录、尾段数据、旧会话隔离、取消、录音错误与超时，以及空音频、静音和 WAV 校验；测试使用模拟输入，不访问真实麦克风或服务。
