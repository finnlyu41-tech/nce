# Private reviewer design notes: lessons 7–12

This is authored guidance for a future authorized human assessment workflow. It is not a connected reviewer, a qualification grant, a learner answer key, or evidence that any learner passed. Production receives LearnerPort only. Both external delivery and review methods remain unavailable, including when browser qualification booleans are true. Do not import this directory into browser modules or publish it as a learner asset.

Use the existing protocol's four separate skill results, original 3/4/4/7-minute limits, held-out pack allocation, help/exposure controls, and original-first-answer preservation. No aggregate four-skill score or IELTS conversion is defined. These new materials and the reused thresholds have not been calibrated for equivalent difficulty.

Listening and reading each have six semantic facts. Accept clear Chinese, a name, pointing documented by an actual examiner, or an equivalent concise meaning. Judge meaning, not exact strings. Current occupation, explicit denial, named owner, and negative ownership are critical; wrong ownership or reversal of an explicit denial cannot be offset by easier facts. The authored reference facts are in `semantic-reference.json`. Scripts are in `audio-scripts.json`, for authoring only. Reading passages are learner stimuli, not a hidden key. Listening, reading, speaking and writing use different named facts and contexts.

The shipped audio is locally synthesized, not a human speaker or human-checked presentation. Its normal playback, `ended` callback, a transcript, or a frontend checkbox cannot prove actual hearing. Its use records reference help before exposing sound and disqualifies independent assessment. No authenticated human presentation is connected in this batch.

Speaking requires an actual qualified listener and interaction: ask about the listener's unknown job, introduce the given fictional occupation and reject the mistaken occupation, ask/respond about current state, ask an unknown owner then communicate the new named owner and colour, and request repetition when needed. Text excerpts cannot establish pronunciation, intelligibility or interaction. Record neutral repetition and substantive prompts separately under the existing protocol. No real person has performed these tasks here.

Writing uses a fictional first-person role and a new coat-return situation. The four purposes are occupation with explicit denial, current state, confirmed named owner with colour and negative self-ownership, and a question about the unknown owner. A natural equivalent expression is acceptable. Familiar memorized construction or copying another skill's facts is not independent performance. Use the existing four-dimension 0–2 rubric only with a qualified human's documented semantic judgment; no pattern matching or automatic marking is supplied.

Learning workspaces, completion declarations, current correction drafts, and separate revisions do not count as held-out passes. Any practice/correction updates that skill's practice time. Submitted first answers, failures, deadlines and previous observations remain unchanged. New-location restoration preserves originals and original due; natural-interval qualification is pending until real verification. Pure model and browser safety fixtures cannot close real 24-hour/7-day, human acoustic, open-expression, or learning-effect acceptance.
