## 与学习闭环的关系

- 诊断短板：整轮提交后按识别、改错、造句显示实际回答与参考是否一致，指出需要核对的题。限定输入与参考不同不直接宣判英文错误。
- 针对训练：单元有目标和先修链接，可按用途、阶段、册数、课次与例句检索；结果可回看对应结构与对比例句。
- 反馈修正：参考和解释在整轮提交后展开；重做切换到另一套真实题，不把选项重排当换题。
- 无提示迁移：开放任务与自查标准通过接口交给现有表达交互。自由表达保留待核对，程序没有检测到常见问题不等于表达正确。
- 延迟复习：至少间隔 24 小时、不同题组、无提示且三题均与参考匹配，才显示延迟异题检验通过。它证明这两组题的表现，不代表整个知识点或雅思能力已掌握。全站复习队列的接线尚由主线完成。

## 接线接口

```tsx
import {GrammarCurriculum} from './grammar-curriculum-ui';

<GrammarCurriculum
  state={state}
  update={update}
  onOpenLesson={(book, lesson) => openExistingLesson(book, lesson)}
  onPracticeGuide={(book, lesson, guideId, task) => {
    // 必须定位实际知识点，不再默认选本课第一个。
    // task 可选：{unitId, prompt, criteria}；保留它以展示本轮新情境。
    openExistingExpression(book, lesson, guideId, task);
  }}
/>
```

`onPracticeGuide` 的第四参是向现有表达路径提供新情境；原三参调用兼容。组件只从实际教材映射选择入口，按册筛选的基础讲解与迁移链接优先使用同册真实匹配。它没有实现第二套开放表达或录音持久化。

数据 API：`grammarUnits`、`grammarStages`、`grammarPurposes`、`searchGrammarUnits`、`searchGrammarConcepts`、`lessonsForGrammarUnit`、`grammarPracticeLink`。数字和册数必须在同一关联里匹配；第一册偶数课定位到真实奇偶课组。

持久化使用 `State.drafts['grammar-curriculum-v1-'+unitId]`，与原表达草稿分开。每个回答上限 1000 字，历史保留最近 12 轮；无需改 State schema。现有 State 校验只限制 drafts 键数和字符串类型，保存文件总体上限 25 MB，本轮实际往返样本为 8292 字节。缺失或损坏的可选草稿恢复为空；较旧内容版本不继承当前检验证据；较新格式或内容版本拒绝写入覆盖。看过、旧完成勾选、旧 worked 与旧自由表达均不迁移为新检验证据。

使用提示、回看讲解、经目录或先修回看材料会保留本轮帮助标记。练习中隐藏对比例句、开放迁移与关联资料，提交前不展示评分或答案。未来时间记录保留但当下不授予独立或延迟检验证据。
